# YOBA COUTURE

Vitrine et prise de commande en ligne pour l'atelier YOBA COUTURE.

Voir le cahier des charges pour la spécification complète du projet, et `PROGRESS.md` pour l'avancement.

## Pile technique

- React 19 + Vite + TypeScript
- Tailwind CSS 4
- Supabase (base de données, authentification, stockage)
- Netlify (hébergement, Edge Functions)

## Démarrage

```bash
npm install
cp .env.example .env   # renseigner les variables Supabase
npm run dev
```

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run lint` — lint du code
- `npm run preview` — prévisualisation du build
